# Morning rundown

Use the CallFundr connector tools. Never guess — every fact comes from a tool result.

1. List today's appointments with list_appointments (today's date range); note which have no technician. Check list_inquiries for new calls/texts not yet turned into jobs.
2. Group by technician in time order: window, customer, city, the problem in a few words, status.
3. Put first, in one short list: unassigned jobs, anything flagged for a callback, and jobs already running late.
4. End with one line: how many jobs, how many assigned, how many still open.

Keep it short and scannable. Offer the obvious next step ("Want me to assign the two open jobs?") — do not change anything unless the user says so. Any change runs through the tool's preview and waits for the user's yes.
